## 2. 问题1-3：固定半径的统一守恒方程

在 `0<r<R0` 上，以圆柱坐标的散度形式写为：

\[
\rho(C)c_p(C)\frac{\partial T}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}
\left[r k(C)\frac{\partial T}{\partial r}\right],
\]

\[
\frac{\partial C}{\partial t}
=\frac{1}{r}\frac{\partial}{\partial r}
\left[r D(C,T_K)\frac{\partial C}{\partial r}\right].
\]

初始条件：

\[
T(r,0)=28\;^\circ\mathrm C,\qquad C(r,0)=2.55.
\]

中心对称边界：

\[
\frac{\partial T}{\partial r}(0,t)=0,\qquad
\frac{\partial C}{\partial r}(0,t)=0.
\]

表面 Robin 边界：

\[
-k\frac{\partial T}{\partial r}(R,t)=h\,[T(R,t)-T_\infty(t)],
\]

\[
-D\frac{\partial C}{\partial r}(R,t)=h_m\,[C(R,t)-C_\infty(t)].
\]

### 符号方向的两项物理检查

1. 预热阶段通常 `T∞>Ts`，右端为负，因此向外热通量 `-kT_r<0`，含义是热由表面流入药材，符号正确。
2. 干燥阶段通常 `Cs>C∞`，右端为正，因此向外水分通量 `-DC_r>0`，含义是水分由药材流向烘房，符号正确。

若数值结果长期显示“表面比中心更冷”或“表面比中心更湿”，先检查边界符号和单位，不能直接裁剪结果。

## 3. 问题4：收缩移动边界的材料坐标表达

定义材料坐标 `ξ=r/R(t)`，以及材料点速度

\[
u(r,t)=\frac{r\dot R(t)}{R(t)}.
\]

本题把 `C` 解释为随固体骨架运动的干基含水率。相对于固体骨架的守恒方程在欧拉坐标中写作：

\[
\frac{\partial C}{\partial t}+u\frac{\partial C}{\partial r}
=\frac{1}{r}\frac{\partial}{\partial r}
\left(rD\frac{\partial C}{\partial r}\right).
\]

相同思想用于热方程的材料导数。变换到 `ξ` 后，材料导数就是 `∂/∂t|_ξ`，故固定参考域上的水分方程为：

\[
\frac{\partial C}{\partial t}\bigg|_{\xi}
=\frac{1}{R(t)^2\xi}\frac{\partial}{\partial\xi}
\left[\xi D(C,T_K)\frac{\partial C}{\partial\xi}\right].
\]

温度方程同理：

\[
\rho(C)c_p(C)\frac{\partial T}{\partial t}\bigg|_{\xi}
=\frac{1}{R(t)^2\xi}\frac{\partial}{\partial\xi}
\left[\xi k(C)\frac{\partial T}{\partial\xi}\right].
\]

边界条件仍保持同一物理含义：

\[
-\frac{k}{R}\frac{\partial T}{\partial\xi}(1,t)=h[T(1,t)-T_\infty(t)],
\]

\[
-\frac{D}{R}\frac{\partial C}{\partial\xi}(1,t)=h_m[C(1,t)-C_\infty(t)].
\]

**禁止双重计入收缩速度：** 若程序在材料坐标 `ξ` 上实现上述方程，就不能再额外加 `ξ\dot R/R·∂C/∂ξ` 项；该项只会出现在从固定空间坐标方程做变量替换、却没有先写出材料对流速度的错误混合写法中。

## 4. 附件与边界的固定规则

1. 附件1从 0 到 14400 s、每 60 s 记录环境数据。正式主方案采用分段线性插值，不用全局高阶拟合。
2. `t>14400 s` 的主方案固定为 `(T∞,C∞)=(50°C,0.05 kg/kg)`；必须和“末点保持”“末30 min均值保持”进行敏感性比较。
3. 附件2半径使用保形单调插值。超过 259200 s 时暂定保持末半径，并在结果中记录是否发生外推。
4. 所有 `exp(-3850/T)` 均使用 K。代码中不允许出现将摄氏温度直接传入 `D` 的调用。
