# 钢包运动情况

以钢包为跟踪对象，记录所在位置、运输设备和有无钢水。转炉出钢后转为重包，完成浇铸后进入空包回程。

| 位置/设备 | 钢包在此处的动作 | 钢包状态 |
|---|---|---|
| 转炉钢包车 | 承接空包、接收转炉出钢、移动至吊罐位置 | 接钢前（无钢水），接钢后有钢水 |
| LF精炼位 | 加热、调温、调成分 | 有钢水 |
| RH精炼位 | 真空脱气 | 有钢水 |
| 连铸机 | 座包、等待、开浇、终浇 | 浇铸过程中有钢水，浇毕进入空包回程 |
| 行车 | 吊起、搬运、落下钢包 | 搬运重包，也承担空包吊运（无钢水） |
| 平车/渡车 | 承接行车放下的空包，沿地面线路转运 | （无钢水） |
| 翻渣/回收位 | 处理铸余、残钢与残渣 | 按实际残余量记录，处理后（无钢水） |
| 热修位 | 检修、整备，准备下一次接钢 | （无钢水） |

下文“（无钢水）”表示空包循环状态；铸余和残渣的处理动作另列，运输载荷按实际总重量记录。

# 精炼情况分类

## 1. 只有RH或LF

### 仅RH

```text
转炉钢包车（无钢水）
  → 转炉出钢，钢水装入钢包
  → 钢包车移动至吊罐位置
  → 行车吊运重包
  → RH接受位 → RH处理位 → RH吊罐位
  → 行车吊运重包
  → 连铸机接受位 → 开浇 → 终浇
  → 空包回程
```

### 仅LF

```text
转炉钢包车（无钢水）
  → 转炉出钢，钢水装入钢包
  → 钢包车移动至吊罐位置
  → 行车吊运重包
  → LF待机位 → LF处理位 → LF待机/吊罐位
  → 行车吊运重包
  → 连铸机接受位 → 开浇 → 终浇
  → 空包回程
```

## 2. RH→LF或LF→RH

### RH→LF

```text
转炉钢包车（无钢水）
  → 转炉出钢，钢水装入钢包
  → 钢包车移动至吊罐位置
  → 行车吊运重包
  → RH接受位 → RH处理位 → RH吊罐位
  → 行车吊运重包
  → LF待机位 → LF处理位 → LF待机/吊罐位
  → 行车吊运重包
  → 连铸机接受位 → 开浇 → 终浇
  → 空包回程
```

### LF→RH

```text
转炉钢包车（无钢水）
  → 转炉出钢，钢水装入钢包
  → 钢包车移动至吊罐位置
  → 行车吊运重包
  → LF待机位 → LF处理位 → LF待机/吊罐位
  → 行车吊运重包
  → RH接受位 → RH处理位 → RH吊罐位
  → 行车吊运重包
  → 连铸机接受位 → 开浇 → 终浇
  → 空包回程
```

RH/LF内部接受、处理和吊罐位置之间的转位记为设备内部动作；跨设备运输记为行车任务。

## 3. 四种路线共用的空包回程

```text
连铸机终浇
  → 行车吊离浇毕钢包
  → 翻渣/铸余回收位，完成残余物处理
  → 行车吊运（无钢水）
  → 放到1#、2#或3#平车（无钢水）
  → 平车转运至整备跨（无钢水）
  → 整备跨行车吊至热修位（无钢水）
  → 热修、整备（无钢水）
  → 整备跨行车吊放到回程平车（无钢水）
  → 平车返回转炉侧衔接区域（无钢水）
  → 所在跨行车吊至指定转炉钢包车（无钢水）
  → 转炉钢包车等待接钢（无钢水）
  → 下一炉出钢，重新成为重包
```

回程按“吊离—回收/翻渣—放平车—热修—返回”跟踪。各炉次的回收分支、平车与转炉衔接路径由实际事件链展开。

## 4. 运动与状态记录

| 字段 | 内容 |
|---|---|
| ladle_id | 物理钢包号，跨炉次持续跟踪 |
| heat_id | 本次接钢对应的熔炼号，空包回程关联刚完成的炉次 |
| location | 当前设备、工位、行车或平车位置 |
| movement_type | 行车吊运、平车转运、设备内部转位、工序处理或等待 |
| steel_state | 有钢水、浇毕待残余处理、（无钢水） |
| carrier_id | 执行运输的行车号或平车号 |
| event_time | 吊起、到达、放下、处理开始/结束等事件时刻 |
| gross_load | 钢包及内容物的总重量 |

四种路线从转炉接钢到连铸的跨设备重包运输分别为2、2、3、3段；设备内部转位和空包回程分段单独统计。
