# 钢包运动情况
- 转炉
- 精炼位：RH,LF
- 连铸机
- 平车：运空钢包
- 行车：运带钢水钢包
行车负责吊运重包和空包；平车负责空包的地面转运。
# 精炼情况分类
## 只有RH或LF
## RH->LF或LF->Rh
# 转炉到钢包
接钢阶段
转炉钢包车（无钢水）→ 转炉出钢入包 → 钢包车移至吊罐位 → 行车吊起重包。
# 运钢时钢包在哪
只有RH或LF
- 仅RH：行车 → RH精炼位 → 行车 → 连铸机。
- 仅LF：行车 → LF精炼位 → 行车 → 连铸机。
RH→LF或LF→RH
- RH→LF：行车 → RH精炼位 → 行车 → LF精炼位 → 行车 → 连铸机。
- LF→RH：行车 → LF精炼位 → 行车 → RH精炼位 → 行车 → 连铸机。
以上精炼、运输和浇铸过程中，钢包均装有钢水。
