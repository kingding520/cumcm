# 炼钢总体流程与所需设备对照


## 1. 总体流程

**铁水来料 → 转炉冶炼、出钢入包 → 按计划精炼 → 连铸成坯。**

**钢包循环：空包准备 → 转炉接钢 → 随钢水完成精炼、连铸 → 空包吊离 → 翻渣 → 过渡平车转运 → 热修 → 返回转炉区域。**

钢坯是产品出口，空钢包回程是容器循环，两条流向在连铸后分开。工序之间的钢包吊运由行车衔接，渡车承担指定位置的地面转运。

## 2. 流程—设备一一对照表

| 顺序 | 工序/动作 | 输入 → 输出 | 直接所需设备 | 本题编号/数量 | 衔接与调度要求 |
|---|---|---|---|---|---|
| 0 | 铁水供应 | 高炉铁水 → 转炉原料 | 高炉、铁水运输设施 |设备数量|  |
| 1 | 空包就位、等待接钢 | 整备后的空钢包 → 可接钢状态 | 钢包、转炉钢包车、行车 | 钢包充足，行车2+3=5台 |
| 2 | 转炉冶炼与出钢 | 铁水 → 初炼钢水装入钢包 | 转炉、钢包及接钢位置 | A、B、C，共3座转炉 | 出钢完成不等于立即可吊，还需钢包车/工位释放条件满足 |
| 3 | 转炉至首道精炼运输 | 转炉区域重钢包 → LF或RH接收位 | 行车、钢包、目的设备接受位 | 5台行车中的合法可用车辆 | 总吊重需含钢水与钢包自重，并满足行车覆盖与安全间距 |
| 4A | LF精炼（按路线选用） | 钢水 → 调整成分和温度后的钢水 | LF钢包精炼炉 | 1#LF、2#LF，共2台 | 电极加热、吹氩；仅LF路线处理后去连铸，LF→RH路线还需去RH |
| 4B | RH精炼（按路线选用） | 钢水 → 真空脱气后的钢水 | RH真空循环脱气装置 | 1#RH、2#RH，共2台 | 仅RH路线处理后去连铸，RH→LF路线还需去LF |
| 5 | 两道精炼间运输（双精炼路线） | LF出站重包 → RH，或RH出站重包 → LF | 行车、钢包、下一设备接受位 | 同一组行车资源 | 仅双精炼路线有此任务；不能把LF→RH固定为所有炉次顺序 |
| 6 | 末道精炼至连铸运输、座包 | 精炼合格钢水 → 连铸机可供钢状态 | 行车、连铸接受位/大包回转臂、钢包 | 1#、2#、3#连铸对应接受位置 | 到达、座包、开浇分开记录；具体臂位容量与切换互锁待核实 |
| 7 | 连续浇铸 | 钢水 → 钢坯＋空钢包 | 连铸机、中间包、结晶器 | 1#、2#、3#，共3台连铸机 | 同浇次炉序和连续供钢要求需满足；中间包、结晶器属于连铸系统，不另加为独立整机数量 |
| 8 | 空包吊离、翻渣/残余物处理 | 浇毕钢包 → 排渣后的空包 | 行车、翻渣/回收设施 | 翻渣与铸余回收为题面所列环节，数量待核实 | 空包运输同样占用行车；具体回收分支以事件链为准 |
| 9 | 过渡平车转运 | 空包 → 热修衔接区域 | 行车、过渡平车（渡车） | 题文限定空包回程只能落到1#、2#、3#渡车 | 行车吊放与渡车地面转运分开建任务，不能视作同一设备 |
| 10 | 热修、整备 | 待修空包 → 可再次使用的钢包 | 热修工位及配套设施 | 题文明确环节，工位数量/容量待核实 | 工位占用与维修时间纳入回程；不虚设固定热修容量 |
| 11 | 返回转炉区域 | 整备完成钢包 → 下一炉接钢准备 | 行车、相关转运设施、钢包车 | 按实际回程连接关系确认 | 回到步骤1，形成闭环；具体换车点、路径与覆盖范围待核实 |

表中4A、4B是精炼类型，不表示每炉必须先4A再4B。行车是多环节共享设备，表中重复出现不代表新增车辆。

## 3. 四种精炼路线与设备串联

| 出钢计划路线 | 完整重包工艺链 |
|---|--- |
| 仅LF | 转炉 → LF → 连铸机 |
| 仅RH | 转炉 → RH → 连铸机 | 
| LF→RH | 转炉 → LF → RH → 连铸机 | 
| RH→LF | 转炉 → RH → LF → 连铸机 | 

## 4. 设备总账与资源类别

| 类别 | 设备 | 题面/附件口径 | 用途及不能混淆之处 |
|---|---|---|---|
| 生产设备 | 转炉 | 3座：A/B/C | 冶炼、出钢 |
| 生产设备 | LF精炼炉 | 2台：1#、2# | 调成分、温度；不是所有炉次必经 |
| 生产设备 | RH装置 | 2台：1#、2# | 真空脱气；不是所有炉次必经 |
| 生产设备 | 连铸机 | 3台：1#、2#、3# | 将钢水连续浇铸成坯 |
| 吊运设备 | 150吨行车 | 2台：1#、2# | 任务是否可接由总吊重、覆盖与可达性决定 |
| 吊运设备 | 450吨行车 | 3台：3#、4#、5# | 可执行符合条件的重包及空包任务 |
| 地面转运设备 | 渡车/过渡平车 | 空包回程允许落点为1#、2#、3# | 不等于行车；其具体承载与占用能力待核实 |
| 接钢/转位设备 | 转炉钢包车 | 有相关事件记录，数量待核实 | 承接钢包、参与工位转位，与渡车编号不能直接等同 |
| 循环容器 | 钢包 | 数量充足 | 钢包号不同于熔炼号；同一个钢包可先后服务不同炉次 |
| 整备设施 | 翻渣、铸余回收、热修设施 | 环节已知，数量和兼容关系待核实 | 不能因钢包充足而删除空包运输或整备任务 |
| 待机/维护位置 | 烘烤、冷修、拆罐位等 | 图1有相关标注，容量与启用条件待核实 | 不自动作为每炉必经步骤，也不默认可作任意中转缓存 |


行车有#、2#两台行车，每台的吊运能力为150吨，3#、4#、5#三台行车，每台的吊运能力为450吨，它们共享同一轨道，行车间不能相互跨跃，行车运行冲突会约束排产。
