# 流程
| 出钢计划路线 | 完整重包工艺链 |
|---|--- |
| 仅LF | 转炉 → LF → 连铸机 |
| 仅RH | 转炉 → RH → 连铸机 | 
| LF→RH | 转炉 → LF → RH → 连铸机 | 
| RH→LF | 转炉 → RH → LF → 连铸机 | 
# 炼钢设备
- 转炉:ABC三台
- LF：两台
- RH：两台
- 连铸机：三台
# 运输设备
- 包钢：充足
- 行车：吊有钢水的钢包
- 平车：运空钢包
| 设备 | 作用与使用场景 | 数量 |
|---|---|---|
| **行车（吊车）** | 吊起并运输钢包，连接转炉、LF、RH、连铸等工序；也承担空包回程吊运 | **5台**：1#、2#各150吨；3#、4#、5#各450吨 |
| **平车（渡车）** | 在地面承接钢包并沿固定线路转运，衔接空包回程、热修等区域；钢包由行车吊放到平车上 | 题面明确空包回程可落到 **1#、2#、3#，共3台渡车**；全厂平车总数未明确 |
